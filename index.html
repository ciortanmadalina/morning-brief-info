Morning Brief

Selected newsletters, news, and weather in one daily email.

Purpose

Morning Brief is a private automation operated by Madalina Ciortan for personal use. It combines selected Gmail newsletters, public news, and weather, then emails a digest to the recipients configured by its owner. It is not a public sign-up service.

Google account access

The owner authorizes Gmail read and send access through Google OAuth. Newsletter retrieval is limited by the application to configured labels and time windows. Read access also verifies the account and checks sent-message records to prevent duplicate delivery. Google grants mailbox-level scopes; it does not enforce the application's label filter.

Selected newsletter text is sent to the Anthropic API for summarization. Scheduled processing runs on Railway. The owner can also run previews locally.
